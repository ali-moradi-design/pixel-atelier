# Security policy

## Supported versions

The latest minor release of `pixel-atelier` receives security fixes.

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private vulnerability
reporting (Security → Report a vulnerability) on this repository. You will get
an answer within a few days; fixes are released as patch versions and noted in
the changelog.

## What is in place

See [`docs/security.md`](docs/security.md).
