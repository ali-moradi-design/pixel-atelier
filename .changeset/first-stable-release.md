First stable release: 39 components (core, forms, overlays, data display and the pixel signature effects), 5 blocks, the pixel primitives, the Tailwind v4 theme and a precompiled stylesheet. Every component is its own tree-shakable entry, documented with TSDoc, tested with Vitest, Testing Library and axe, and checked in a real browser for visual regressions and color contrast.
