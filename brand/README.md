# Brand

Logo of Pixelbits: a brilliant-cut gem drawn in pixels (13 x 9), lit from
the top left. Four tones of the gold ramp shade the table, crown and pavilion;
the facet lines and the girdle are cut out as negative space. The wordmark is
"Pixelbits" in Story Script.

| File | Use |
| --- | --- |
| `mark-on-dark.svg`, `mark-on-light.svg` | Gem only, gold tones for each background |
| `mark-mono.svg` | Gem only, `currentColor` (inline SVG) |
| `logo-on-dark.svg`, `logo-on-light.svg` | Gem + wordmark |
| `logo-mono.svg` | Gem + wordmark, `currentColor` |
| `favicon.svg` | 16 px (1 px per cell), follows `prefers-color-scheme` |
| `favicon.ico` | 16 px + 32 px fallback |
| `apple-touch-icon.png`, `icon-512.png` | App icons on the dark tile |
| `social-preview.png` | GitHub / Open Graph image, 1280 x 640 |

- Gold ramp (tokens, OKLCH): `#fee06b #edc538 #caa22e #a47e20 #815c12`.
  Dark backgrounds use tones 100/200/300/500, light backgrounds 200/300/400/500.
- Backgrounds: dark `#0d0d0f`, light `#f6f4ef`; wordmark ink `#f2efe8` / `#151514`.
- Keep at least two cells of clear space around the gem. Do not add seams
  between the squares other than the facet cuts.
- Wordmark font: Story Script (`source/StoryScript-Regular.ttf`, SIL Open
  Font License, see `source/OFL-StoryScript.txt`).

All files are generated by `source/build.mjs` from one grid (the same grid as
`apps/docs/components/layout/logo.tsx`). It needs `opentype.js`, `png-to-ico`
and `playwright`; copy it next to its font into a folder where they are
installed and run `node build.mjs <path-to-brand>`.
