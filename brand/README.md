# Brand

Logo of Pixel Atelier (concept P1): a solid 8 x 8 pixel tile with a
negative-space "P"; its bottom-right corner breaks up into loose pixels, one of
them in the accent color. It is the kit's hover effect frozen in one frame.

| File | Use |
| --- | --- |
| `mark-on-dark.svg`, `mark-on-light.svg` | Mark only, two colors |
| `mark-mono.svg` | Mark only, `currentColor` (inline SVG) |
| `logo-on-dark.svg`, `logo-on-light.svg` | Mark + wordmark |
| `logo-mono.svg` | Mark + wordmark, `currentColor` |
| `favicon.svg` | 16 px grid (2 px per cell), follows `prefers-color-scheme` |
| `favicon.ico` | 16 px + 32 px fallback |
| `apple-touch-icon.png`, `icon-512.png` | App icons on the dark tile |
| `social-preview.png` | GitHub / Open Graph image, 1280 x 640 |

- Wordmark: "pixel atelier" in Geist (Medium + Light), converted to outlines.
- Colors (gold ramp `#ffe169 #edc531 #c9a227 #a47e1b #805b10`):
  dark `#0d0d0f` / ink `#f2efe8` / accent `#c9a227`;
  light `#f5f2ec` / ink `#151514` / accent `#805b10`.
- Keep at least one cell of clear space around the mark. Do not add seams
  between the squares: the "P" stops reading.

All files are generated by `source/build.mjs` from one grid. It needs
`playwright`, `opentype.js`, `png-to-ico` and `geist`; it will move into the
monorepo tooling once that exists.
